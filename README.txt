Reglas implementadas:

Regla 1- Evalúa si el uso de CPU esta en el rango esperado

Regla 2- Evalúa si el uso de la RAM esta en el rango esperado

Regla 3- Evalua si el uso de CPU o RAM y la cantidad de procesos sobrepasa los limites esperados

Regla 4- Evalua si la cantidad de procesos es mas alta de lo esperado para la cantidad de usuarios

Regla 5- Evalua si hay alta demanda o poco espacio para el tipo de servidor de archivos

Regla 6- Evalua i hay sobrecarga de usuarios para el tipo de servidor web

Regla 7- Evalua si el firewall esta activo y en caso de haber usuarios conectados da una señal de alerta

Regla 8- Evalua el espacio del disco y la cantidad de procesos para dar aviso a cuando se acaben los recursos
